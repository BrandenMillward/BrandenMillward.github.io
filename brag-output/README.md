# /brag output

A short launch video for this site, generated by the [`/brag`](https://github.com/latent-spaces/brag)
skill via [Hyperframes](https://hyperframes.heygen.com/).

| File | What it is |
|---|---|
| `brag.mp4` | The video. 21.4s, 1920x1080, H.264 + AAC. |
| `brag.jpg` | The poster frame, pulled at 13.5s. Also baked as frame 0 of the MP4, so platforms that grab frame 0 for a thumbnail get this rather than a fade. |
| `brag-plan.md` | The creative plan and the beat-by-beat storyboard. |
| `composition-brief.md` | The brief handed to Hyperframes. |
| `share-copy.txt` | The caption. |
| `composition/` | The Hyperframes project the video renders from. |

## What it shows

The site's argument, assembled: the hook ("Most organisations don't have an AI
problem. They have a trust problem."), then the nine-layer agent architecture
building top to bottom in flow order, then a simulated click on GOVERNANCE that
opens its real evidence line, then the h1 and the domain.

The diagram is rebuilt from `index.html`'s `.net-svg` at the same 400x325 viewBox
and the same geometry, so it stays in step with the live hero. The ochre on
GUARDRAILS and GOVERNANCE is `--accountable`, used with the same meaning it
carries on the site: a human stays answerable there.

## Re-rendering

```bash
cd composition
npx hyperframes check     # lint, runtime, layout, motion, contrast. Must be 0 errors.
npx hyperframes render --output ../brag.mp4
```

Needs Node 22+, FFmpeg on `PATH`, and a headless Chrome
(`npx hyperframes browser ensure`).

Two files the composition needs are **not** committed:

- `composition/assets/music/happy-beats-business-moves-vol-10-by-ende-dot-app.mp3` —
  gitignored. The brag skill's own asset README states the music licence terms are
  unverified, so the track is not redistributed from this repo. Copy it back from
  `~/.claude/skills/brag/assets/music/` to re-render with sound.
- `composition/assets/audio-data.json` — the full-track extraction intermediate.
  Only the derived `assets/audio-data.js` (the per-frame energy the diagram breathes
  on) is tracked. Regenerate the intermediate with the `extract-audio-data.py` script
  in the `hyperframes-creative` skill if you need it.

The SFX are Kenney (CC0), the fonts are the same Google Fonts the site loads, and
GSAP is vendored locally because the render browser has no route to the CDN.
